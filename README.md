# ALEKS Progress Tracker

A teacher dashboard for cycles, class goals, attendance and learning progress.

## Public demonstration and privacy

The public demo uses fictional learners and a local query simulator. No Supabase account or school database is contacted. Open index.html; a demo teacher is selected automatically.

Use fictional information when exploring the demo. Public source code, browser controls and client-side filters are not access controls for a real deployment.

## Run locally

Serve the repository with a static web server, for example `python -m http.server 8000`, and open the page in your browser. See [SECURITY.md](SECURITY.md) for security boundaries and validation.
